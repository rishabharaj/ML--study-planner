# Fieldnotes — Machine Learning Study Plan

A standalone, responsive study app built around the revised 28-day roadmap in the supplied conversation.

## Run it

Open `index.html` in a modern browser. No install, account, server, or internet connection is needed for the app itself. Learning-resource links open their source websites and require internet access.

## What it includes

- Dashboard with overall and weekly progress, next session, and project milestone
- 28 day-by-day sessions with a learning goal, where to study, curated links, coding exercise, three checkpoint questions, and completion goal
- Four weekly mini-projects that lead to an end-to-end churn prediction app
- Optional library projects for PyTorch, FastAPI/Pydantic, and XGBoost after the core path
- A separate 8-week advanced track after Day 28: MLOps, experiment tracking, API/container/CI, monitoring, GenAI, RAG, MCP agents, and an industry-style capstone
- Focus timer with 25, 50, and 120 minute presets
- Searchable, filterable Resources tab with official library guides and recommended learning resources separated from user-provided source material
- Per-day notes, completion tracking, and focus time saved in browser local storage
- Optional extension-project completion tracking, also saved locally
- Progress tracking for all 40 sessions in the 8-week extension

Progress and notes stay in the browser on the device where you use the app. Use **Reset progress** to clear them.

The source conversation provided the revised sequence and summarized NotebookLM roadmap. It did not provide the original NotebookLM attachment contents or lesson timestamps, so the app avoids claiming unverified source-specific lesson sections.
